03 Google Firebase là gì?

🚀 Nền tảng BaaS Toàn diện
Phát triển bởi Google, cung cấp toàn bộ hạ tầng Backend dưới dạng dịch vụ: Database, Auth, Storage, Analytics, Serverless Functions.
⚡ Tối ưu cho Flutter
Bộ SDK FlutterFire chính thức được Google hỗ trợ đa nền tảng (Web, Android, iOS, Desktop) với cú pháp Dart tự nhiên và type-safe.
🔄 Realtime & Offline
Cơ chế Snapshot Stream tự động đồng bộ thay đổi tức thời và cache dữ liệu cục bộ khi mất kết nối mạng Internet.

💡 Tại sao chọn Firebase cho ứng dụng Quản lý Tài liệu? Nhóm không phải tốn thời gian xây dựng REST API, quản lý máy chủ Linux, hay bảo trì chứng chỉ SSL. Toàn bộ trọng tâm được dồn vào chuẩn hóa Kiến trúc Cashew ở Client và mang lại trải nghiệm mượt mà cho sinh viên.

04 So sánh: Tự dựng Backend vs. Firebase BaaS

Tiêu chí Đánh giá Tự dựng Backend (Node.js/Spring Boot + VPS) Google Firebase BaaS (Lựa chọn của Nhóm)
Thời gian triển khai 2 - 4 tuần (Viết code API, DB schema, Deploy) Vài giờ (FlutterFire CLI cấu hình tự động)
Vận hành & Bảo trì Cần kỹ sư DevOps vá lỗi OS, Docker, Firewall, Nginx Google quản lý 100%, đảm bảo SLA 99.95%
Xác thực (Authentication) Tự mã hóa bcrypt, JWT token, session, OAuth refresh Firebase Auth tích hợp sẵn Google Sign-In đa nền tảng
Lưu trữ tập tin lớn (PDF) Tự cấu hình FTP hoặc kết nối AWS S3 phức tạp Firebase Cloud Storage kèm Google CDN toàn cầu
Chi phí khởi điểm Tốn tiền thuê VPS cố định hàng tháng ($5 - $20/tháng) 0 VNĐ (Gói Spark Miễn phí), cực kỳ hào phóng

05 Các Dịch vụ Firebase Cốt lõi trong Dự án

🔐 Firebase Authentication
• Đăng nhập 1-chạm bằng tài khoản Google.
• Chuẩn bảo mật OAuth 2.0 / OpenID Connect.
• Cung cấp định danh duy nhất User.uid làm khóa phân vùng dữ liệu cá nhân của sinh viên.
📂 Cloud Firestore
• Cơ sở dữ liệu NoSQL dạng Document-Collection phân tán.
• Hỗ trợ ghi theo lô (WriteBatch) cam kết toàn vẹn danh sách tài liệu và môn học.
• Dữ liệu lưu tại: /users/{uid}/documents/
☁️ Firebase Cloud Storage
• Lưu trữ các tệp tin bài giảng dung lượng lớn (PDF, Slide, DOCX, Ảnh tóm tắt).
• Tự động sinh đường dẫn tải xuống an toàn (Download URL) gắn với tài liệu học tập.

06 Kiến trúc Cashew Tích hợp Cloud (Local-First)

📱 Tầng Cục bộ: Drift / SQLite
• Đóng vai trò là Single Source of Truth trên thiết bị người dùng.
• Người dùng có thể đọc, tạo, chỉnh sửa, gắn tag, tìm kiếm tài liệu mà không cần kết nối mạng.
• Tốc độ truy vấn tức thì (Độ trễ = 0ms).
☁️ Tầng Đám mây: Google Firebase
• Đóng vai trò là Tầng Đồng bộ & Sao lưu Phân tán (Remote Backup & Cross-Device Sync).
• Khi có mạng Internet, người dùng kích hoạt đồng bộ để đẩy bản ghi SQLite lên Firestore và tập tin lên Storage.
💎 Tuân thủ nghiêm ngặt 4 Tầng Kiến trúc Cashew
[UI Screens: SettingsScreen / HomeScreen] ──▶ [State: AuthProvider / DocumentProvider]
──▶ [Domain Services: AuthService / FirebaseSyncService] ──▶ [Data Layer: AppDatabase & Firebase SDK]

12 Triển khai Tầng Domain: AuthService

📁 lib/domain/services/auth_service.dart
class AuthService {
  final FirebaseAuth _auth = FirebaseAuth.instance;
  final GoogleSignIn _googleSignIn = GoogleSignIn(scopes: ['email', 'profile']);

  /// Hỗ trợ cả Web Popup và Native Mobile Google Sign-In
  Future<UserCredential?> signInWithGoogle() async {
    if (kIsWeb) {
      final provider = GoogleAuthProvider()..addScope('email');
      return await _auth.signInWithPopup(provider);
    } else {
      final googleUser = await _googleSignIn.signIn();
      if (googleUser == null) return null;
      final googleAuth = await googleUser.authentication;
      final credential = GoogleAuthProvider.credential(
        accessToken: googleAuth.accessToken,
        idToken: googleAuth.idToken,
      );
      return await _auth.signInWithCredential(credential);
    }
  }
}

13 Triển khai Tầng Domain: FirebaseSyncService

📁 lib/domain/services/firebase_sync_service.dart
class FirebaseSyncService {
  final FirebaseFirestore _firestore = FirebaseFirestore.instance;
  final FirebaseStorage _storage = FirebaseStorage.instance;

  /// Cam kết nguyên khối theo WriteBatch lên Firestore
  Future<void> syncDocumentsToFirestore({
    required String userId,
    required List<Document> documents,
    required List<Subject> subjects,
  }) async {
    final batch = _firestore.batch();
    final userDoc = _firestore.collection('users').doc(userId);

    for (final s in subjects) {
      batch.set(userDoc.collection('subjects').doc(s.subjectPk), s.toJson());
    }
    for (final d in documents) {
      batch.set(userDoc.collection('documents').doc(d.documentPk), d.toJson());
    }
    await batch.commit(); // Đảm bảo ACID Atomic Sync
  }
}

14 Thiết lập Quy tắc Bảo mật (Security Rules)

🛡️ firestore.rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Mỗi sinh viên chỉ truy cập dữ liệu của chính mình
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null 
                         && request.auth.uid == userId;
    }
  }
}
🛡️ storage.rules
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // Tệp tin PDF chỉ tải lên/xuống theo userId khớp UID
    match /users/{userId}/{allPaths=**} {
      allow read, write: if request.auth != null 
                         && request.auth.uid == userId;
    }
  }
}
✔ Bảo mật cấp trường/tài khoản: Ngăn chặn hoàn toàn việc người dùng A đọc lén hoặc ghi đè tài liệu của người dùng B, ngay cả khi biết URL hoặc cố tình gọi SDK từ client.

15 Đánh giá Chi phí & Hiệu năng sau Tích hợp

💰 Đánh giá Chi phí (Gói Spark Free)
  • Google Sign-In: Hoàn toàn miễn phí, không giới hạn số tài khoản.
  • Cloud Firestore: Miễn phí 50,000 lượt đọc và 20,000 lượt ghi / ngày.
  • Firebase Storage: Miễn phí 5 GB lưu trữ và 1 GB băng thông tải xuống / ngày.

⚡ Đánh giá Hiệu năng & Trải nghiệm (UX)
  • Tốc độ tức thì (0ms latency): Đọc ghi trên SQLite cục bộ, không phụ thuộc mạng.
  • Không chặn giao diện (Non-blocking): Quá trình đồng bộ chạy Asynchronous nền tảng với thanh báo tiến độ mượt mà.
  • Chống mất mát dữ liệu: Dễ dàng khôi phục tài liệu khi đổi điện thoại hoặc mở app trên trình duyệt Web.
