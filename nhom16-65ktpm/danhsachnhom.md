## Hướng Dẫn Cài Đặt Và Khởi Chạy Ứng Dụng

### 1. Yêu cầu môi trường
- **Flutter SDK**: Phiên bản 3.x trở lên (Channel stable).
- **Dart SDK**: Đi kèm với Flutter SDK tương ứng.
- **Môi trường chạy**: Android Emulator / Thiết bị thật Android (hỗ trợ Camera), hoặc Windows Desktop / Chrome.

### 2. Các bước khởi chạy dự án
1. Mở Terminal / PowerShell và di chuyển vào thư mục mã nguồn của nhóm:
   ```bash
   cd nhom16-65ktpm/src
   ```
2. Cài đặt các gói phụ thuộc (dependencies):
   ```bash
   flutter pub get
   ```
3. Kiểm tra các thiết bị khả dụng:
   ```bash
   flutter devices
   ```
4. Khởi chạy ứng dụng trên thiết bị mong muốn:
   ```bash
   flutter run
   ```
