# Hướng dẫn dùng bộ ảnh tham chiếu với Coding Agent

1. Đọc `01_mockups_ai_generated/SmartNote_UI_Reference_Overview.png` để nắm tổng thể.
2. Mở ảnh theo từng chức năng trong cùng thư mục để phân tích bố cục.
3. Đọc `02_real_app_reference_sources/README_REAL_REFERENCES.md` và mở nguồn screenshot thật tương ứng trước khi chốt thiết kế.
4. Không coi mockup AI là giao diện chuẩn tuyệt đối. Đây là phương án tham khảo ban đầu cho SmartNote.
5. Phân tích và ghi lại: hierarchy, tỷ lệ vùng nội dung, mật độ thông tin, spacing, component, màu sắc, typography, trạng thái và hành vi.
6. Sau khi triển khai Flutter, chụp screenshot ứng dụng và so sánh với mockup đã chọn.
7. Không sao chép nguyên bản thương hiệu, logo hoặc tài sản độc quyền của ứng dụng tham chiếu.
