## Hướng Dẫn Cài Đặt & Khởi Chạy Ứng Dụng

### Yêu cầu môi trường
- Flutter SDK: 3.x
- Dart SDK: 3.x
- Android Studio / VS Code

### Các bước khởi chạy
1. Di chuyển vào thư mục mã nguồn:
   ```bash
   cd nhom07-<ten-lop>/src
   ```
2. Cài đặt các gói phụ thuộc:
   ```bash
   flutter pub get
   ```
3. Khởi chạy ứng dụng:
   ```bash
   flutter run
   ```
